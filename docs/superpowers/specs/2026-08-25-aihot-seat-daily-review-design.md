# AIHOT v1、游资席位扩展与每日复盘中心设计

## 目标

把 OSINT 从实时大屏扩展为适合手机阅读的每日复盘工具：科技新闻接入 AIHOT v1，龙虎榜覆盖更多已知/活跃席位，新闻标签切换不重复等待 AI，并将行情、热点、游资保存为可归档、可分别或合并导出的日报。

## AIHOT v1

- 当前代码和 Git 历史均不存在 `/api/public/*` 调用；这是首次 v1 接入，不存在可迁移的旧 cursor 或 ETag。
- 科技新闻调用 `/api/v1/items?mode=selected&window=7d&by=published&limit=100`，仅纳入最近72小时、selected=true、类别为 ai-models/ai-products/industry 的条目。
- 字段映射：`links.original` 为原文，`links.aihot` 为 AIHOT 站内页，`originalTitle` 为原文标题，`source.name` 为原始来源。
- AIHOT 标题和摘要视为已翻译/已摘要，不再交给 DeepSeek 二次处理；保留 AIHOT 和原文两个链接。
- 已用不带 cursor、`If-None-Match` 的 `/api/v1/selected/snapshot?fields=minimal` 做一次新基线探测，但项目不凭空新增本地精选镜像。
- 用途按用户确认的非商业用途执行，并在页面保留 AIHOT 归因；若未来商业化需重新核对授权。

## 标签切换性能

- 服务端按 story id 缓存 DeepSeek 翻译/摘要；同一新闻进入不同分类时复用分析结果。
- “全部”首屏一次预分析前50条，分类接口只做完整72小时集合过滤、分页和缓存读取。
- 客户端按 `topic/page` 保存已访问快照，返回已访问标签时立即展示并后台刷新。
- 不牺牲服务端分类：分类仍在完整集合上完成，不回退为对当前20条前端筛选。

## 游资与活跃席位

- 已知映射使用精确营业部全名；个人映射统一保留“观察席”，地点/集合身份使用“活跃席”或“散户集合席”。
- 新增北京知春路的不同券商席位、炒股养家常用席位、五个精确拉萨天团席位，并兼容国泰君安→国泰海通、安信→国投等历史名称。
- 禁止券商级模糊映射；苏南帮、北京炒家、瑞鹤仙等无稳定席位者不自动认定。
- 席位榜包含全部已知观察席，以及按当日单日榜买入额排序的前20个普通活跃营业部；普通营业部明确标“活跃席位”。
- 每个席位在 dashboard 响应与 UI 中只展开买入额最高3只股票，并返回 `stockCount` 显示“另有N只”。
- 连续多日榜继续不与单日榜加总。

## 每日复盘中心

- 新增 `OsintDailyReport` 专用表，保存 reportDate、edition、status、payload JSON、generatedAt、finalizedAt；同日版本可重建但旧版可追溯。
- 18:30 生成 A股收盘版：A股/亚洲最新收盘、72小时热点、当日龙虎榜。
- 次日08:15 生成全球终版：补齐欧美最近收盘；所有市场保留 `asOf/status/source`，不冒充同一时点。
- `/osint/reports` 为移动端日报归档；`/osint/reports/[date]` 为单日阅读页。
- 页面提供完整、行情、热点、游资四种打印视图；第一版使用打印友好 HTML + `window.print()` 保存/分享 PDF，不增加 PDF 运行时依赖。
- 所有PDF页面和分享图片必须烧录可见水印 `AlphaPercept · 仅供参考`；打印时每页重复，不能只依赖网页浮层。
- 所有导出必须包含免责声明：`本报告基于公开信息自动整理，仅供学习与复盘参考，不构成投资建议或任何买卖依据。数据可能延迟或存在误差，请以交易所、上市公司及原始来源为准。`
- 缺少水印或免责声明时导出门禁必须失败，禁止生成可分享成果物。
- 日/周/月导航先交付日报；周报、月报作为后续聚合视图，不在本轮写假数据。

## 移动端

- 375px 起单列布局，正文最小16px，数据辅助文字不低于12px。
- 顶部使用可横向滚动的“综合/行情/热点/游资”分段控件；底部固定“导出复盘”按钮。
- 行情由宽表改为卡片，新闻和席位均限制首屏信息密度；PDF使用A4纵向排版与显式分页。

## 盘中异动

- 日报预留“盘中异动”模块：分钟级指数变动与前后60分钟新闻做时间关联。
- UI措辞只能是“同期消息/可能催化”，不能把时间相关直接写成因果。
- 当前没有稳定分钟行情快照存档，本轮先保存结构与空态，不伪造异动数据。

## 安全和发布边界

- 允许新增 Prisma model 和迁移文件；本轮不自动执行生产数据库迁移。
- 不在未再次确认的情况下新增 Vercel cron 或修改生产数据。
- 水印与免责声明属于分享安全门禁，不允许被模板参数关闭。
- AIHOT、东方财富、Bloomberg 等外部源失败时保留来源健康度，不用硬编码内容填充。
