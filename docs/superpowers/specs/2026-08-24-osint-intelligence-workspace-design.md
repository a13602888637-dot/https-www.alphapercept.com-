# OSINT 情报工作台改造设计

日期：2026-08-24  
状态：已获用户原型方向确认，可进入实现

## 目标

把现有 OSINT 页面从“地图大屏”改造成可直接使用、也可供其他 Agent 读取的情报工作台：

1. 补齐关键全球行情并明确数据可信度。
2. 聚合世界热点新闻，以时间轴形式展示。
3. DeepSeek 只负责一句话摘要、今日建议和结构化标签，不展示长篇分析。
4. 提供稳定、版本化、只读的结构化数据接口，供其他 Agent 做进一步分析。

页面的单一任务是：让用户在五分钟内看清全球市场状态、主要热点及数据是否可信。

## 信息架构

### 顶部导航

- 保留：交易台、今日、深度研究、OSINT 情报。
- 隐藏：持仓相关入口。
- 本轮不删除页面、API 或数据模型，避免破坏现有依赖并保留恢复能力。
- “今日”后续收敛为今日行情与交易提示；“深度研究”继续保留。

### OSINT 页面

移除世界地图和独立 AI 分析栏，调整为两栏：

- 左栏约 34%：全球行情。
- 右栏约 66%：世界热点时间轴。
- 顶部：风险脉冲条。
- 底部：数据源健康与 Agent 数据接口状态。

窄屏使用“行情 / 热点”页签，不强行并排两栏。

## 全球行情

### 指标范围

- 全球指数：道琼斯、纳斯达克、标普 500、恒生、日经 225、韩国综合、富时 100、德国 DAX、富时全球、主要 A 股指数。
- 连续期指：NQ、ES、YM、NKD、CN00Y。
- 商品：WTI、Brent、黄金、白银、铜、天然气。
- 外汇：美元指数、USD/CNH、USD/JPY。
- 风险与利率：真实 VIX、美债收益率 1Y、10Y、20Y、30Y。

### 数据契约

每条行情至少包含：

```json
{
  "symbol": "GEISAC.FGI",
  "name": "富时全球",
  "kind": "index",
  "value": 1267.05,
  "change": -2.34,
  "changePercent": -0.18,
  "source": "yahoo",
  "asOf": "2026-08-24T10:05:00Z",
  "status": "live",
  "confidence": "single-source"
}
```

`status` 只允许 `live | cached | stale | unavailable`。`null` 在页面显示为 `—`，不得显示为 `0` 或 `+0.00%`。

### 稳定性

- 停止依赖当前已返回 404 的 Stooq 旧报价端点。
- 全球行情使用已验证的 Yahoo Chart 标的；CN00Y 使用东方财富 `104.CN00Y`；美债使用美国财政部官方收益率曲线。
- 仅缓存成功结果；部分失败不得覆盖对应标的的最近成功值。
- 最近成功值可以降级显示，但必须标为 `cached` 或 `stale`。
- 不使用硬编码行情或 mock 值冒充真实数据。
- 空数组或低覆盖率不得显示为健康状态。

## 世界热点时间轴

### 内容结构

借鉴 AI Hot 的时间轴、筛选和来源展示，但保持本项目的深色交易终端视觉：

- 时间范围：过去 24 小时。
- 筛选：全部、地缘、宏观、能源、科技；支持来源筛选和关键词搜索。
- 每条事件展示：时间、标题、一句话摘要、重要度、来源、原文链接、结构化标签。
- 相同故事按标题和实体相似度去重，保留多个来源作为交叉验证。

### DeepSeek 边界

DeepSeek 只生成：

1. 每条新闻的一句话中文摘要。
2. 页面顶部的一句“今日建议”。
3. 结构化标签。

DeepSeek 失败时仍展示原始新闻；没有足够数据覆盖率时不生成强方向建议。

标签维度：

- `topic`：地缘、宏观、能源、科技、政策、供应链等。
- `region`：中国、美国、欧洲、中东、亚太等。
- `assets`：A 股、美股、原油、黄金、美元、美债等。
- `direction`：risk-on、risk-off、mixed、neutral。
- `horizon`：日内、1-3 天、1-3 周、中期。
- `verification`：单源、双源确认、官方来源。

重要度采用可解释的规则评分：来源数量、来源等级、时效性、市场相关度；不使用不可解释的纯 AI 分数。

## Agent 数据接口

提供公开、只读、版本化 REST v1；不包含自选股、持仓或 Clerk 用户数据。

- `GET /api/osint/v1/context`：行情、热点、标签、今日建议、覆盖率的一体化快照。
- `GET /api/osint/v1/markets`：结构化全球行情。
- `GET /api/osint/v1/stories`：热点事件、一句话摘要、标签和来源。

统一响应包含：

```json
{
  "schemaVersion": "1.0",
  "generatedAt": "2026-08-24T10:06:00Z",
  "coverage": { "available": 18, "total": 21, "ratio": 0.86 },
  "data": []
}
```

接口支持 `ETag`、`If-None-Match` 和合理的 `Cache-Control`。字段在 v1 内不删除、不改名、不改变类型。

本轮不新增长期新闻数据库，也不实现 MCP；REST v1 作为其他 Agent 的最小可靠接入面。后续若需要历史回溯或增量同步，再单独设计持久化和 MCP。

## 新闻与 AI 数据流

1. 读取现有财经源、GDELT、ReliefWeb 等公开数据。
2. 规范化为统一事件结构并去重。
3. DeepSeek 生成一句话摘要和标签；失败时保留原始标题。
4. 计算可解释重要度与数据覆盖率。
5. 同一份结构化结果同时供页面和 REST v1 使用，避免重复请求与口径漂移。

## 页面状态

- 加载：保留上一份成功数据并显示局部刷新状态。
- 部分失败：数据源状态为 degraded，成功部分继续展示。
- 全部失败：明确显示“暂无数据”和失败来源，不伪造平盘值。
- 新闻为空：显示已尝试的来源和下次刷新时间。
- DeepSeek 失败：保留新闻，隐藏 AI 标签或标记“待分析”。

## 视觉方向

- 延续深色交易终端，不照搬 AI Hot 的浅色品牌和侧边栏。
- 背景 `#070B12`、面板 `#0D1420`、分隔线 `#1F2A3A`。
- 主文字 `#D6DEE8`、弱文字 `#718096`、状态青 `#2EC4C7`、上涨红 `#F35A5A`、下跌绿 `#36C878`、风险黄 `#F2B84B`。
- 中文无衬线正文配窄体等宽数字；小圆角、细分隔线、低装饰。
- 每个行情和事件都显示“来源 + 新鲜度/确认度”标签，这是页面的识别性元素。

## 验收标准

1. OSINT 页面不再渲染地图或独立长篇 AI 面板。
2. 关键指标槽位完整，WTI/Brent/VIX/美债产品语义正确。
3. 上游部分或全部失败时不出现假数据、假平盘或假健康状态。
4. 无 DeepSeek key 或 DeepSeek 失败时，原始新闻仍可展示。
5. 新闻时间轴可按分类筛选并显示来源、原文链接和标签。
6. REST v1 返回稳定 schema，公开数据中不含用户身份、持仓或自选股。
7. 顶部导航隐藏持仓入口，保留深度研究；未删除相关页面。
8. 桌面和窄屏均可用，键盘焦点、标签语义和减弱动画设置有效。
9. 聚焦自动验证、类型检查和一次浏览器验收通过；已知仓库既有错误单独记录。

## 不在本轮范围

- 删除持仓页面、API、Prisma 数据模型。
- 长期新闻历史库和跨日增量同步。
- MCP Server、Agent Skill 安装包和 RSS 输出。
- PNG 图片导出。
- 自动交易或对用户资金产生直接操作。
