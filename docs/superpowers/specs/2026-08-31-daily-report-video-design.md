# 每日复盘短视频设计

## 目标

把早报和收盘报告从固定单图升级为在线生成的 9:16 短视频，降低单图模板重复带来的“批量发布或低质内容”风险。系统提供 7 个星期主题，每个主题包含早报和收盘两个明显不同的变体，共 14 种呈现。

## 范围

- 输出：1080×1920、30fps、10–12 秒 WebM。
- 早报：每天可生成，展示 5 条当日重点新闻。
- 收盘：仅当龙虎榜数据日期与报告日期一致时可生成，避免周末或数据延迟时重复旧内容。
- 音频：浏览器内生成 7 套轻量原创提示音，不使用外部音乐、TTS、密钥或付费服务。
- 现有 PNG 下载保留为兜底，不自动发布到抖音。

## 体验

报告页新增“生成早报短视频”和“生成收盘短视频”按钮。点击后加载报告数据、显示生成进度，完成后自动下载。生成过程约等于视频时长。

每条视频结构：

1. 0–1.5 秒：独立封面，日期、主题、当天钩子。
2. 1.5–9.5 秒：分镜信息卡；早报展示 5 条新闻，收盘展示资金变化和活跃席位。
3. 9.5–12 秒：AlphaPercept 品牌、数据截止时间和风险提示。

## 七日主题

1. 周一：坐标网格——深青、轴线入场。
2. 周二：信号波纹——珊瑚红、环形扩散。
3. 周三：模块切片——靛蓝、卡片切换。
4. 周四：数据轨道——赭黄、横向轨迹。
5. 周五：编辑终版——黑白红、杂志式推进。
6. 周六：全球纵览——海蓝、轨道旋转；仅早报。
7. 周日：下周预告——紫灰、日历翻页；仅早报。

主题由报告日期确定，同一日期可重复生成同一结果；早报和收盘共享色彩 DNA，但封面构图、信息层级和动效不同。

## 架构

- `lib/osint/daily-video/contracts.ts`：视频模式、主题、分镜和进度类型。
- `lib/osint/daily-video/themes.ts`：七日主题配置与日期选择。
- `lib/osint/daily-video/storyboard.ts`：从报告快照生成早报/收盘分镜；纯函数、可测试。
- `lib/osint/daily-video/canvas-renderer.ts`：Canvas 绘制封面、卡片、转场与结尾。
- `lib/osint/daily-video/audio.ts`：Web Audio 原创提示音。
- `lib/osint/daily-video/generate.ts`：Canvas captureStream、MediaRecorder、进度和下载。
- `components/osint-reports/ReportVideoActions.tsx`：用户操作与错误提示。

客户端只读调用现有 `/api/osint/v1/reports/[reportId]`。不新增数据库、对象存储或服务端 ffmpeg。

## 失败处理

- 浏览器不支持 MediaRecorder/captureStream：按钮禁用并保留 PNG 下载。
- 收盘数据不新鲜：拒绝生成并显示实际数据日期。
- 报告不足 5 条可用新闻：按实际数量生成，不复制填充。
- 录制失败：释放媒体轨道和 AudioContext，不留下后台任务。

## 验证

- 7 个日期选择 7 个不同主题。
- 同日早报与收盘分镜结构不同。
- 非新鲜收盘数据必须失败关闭。
- 真实 8 月 31 日报告生成 1080×1920 WebM，ffprobe 校验时长、编码和音轨。
- `npm run build` 通过；生产部署后在报告页完成一次真实下载验收。

## 非目标

- 不自动登录或发布抖音。
- 不接入 TTS、版权音乐或第三方视频渲染服务。
- 不删除现有 PNG 导出能力。
