# OSINT 未来事件与三页复盘 PDF 设计

日期：2026-08-26

## 目标

1. 热点区补充未来 7 天的高影响事件，解决用户无法及时看到美联储讲话、重要宏观数据和重点公司财报时间的问题。
2. PDF 改为适合手机转发的固定三页结构，不再输出十余页长报告。

## 已核实的当前事件

- 2026-08-26 20:30（北京时间）：美国 BEA 同时公布二季度 GDP 第二次估计、企业利润，以及 7 月个人收入与支出/PCE。
- 2026-08-27 04:20 左右（北京时间）：NVIDIA 预计公布 FY2027 Q2 财务结果和 CFO 书面评论。
- 2026-08-27 05:00（北京时间）：NVIDIA FY2027 Q2 财报电话会。
- 2026-08-28 22:00（北京时间，按美东时间换算）：美联储主席 Kevin Warsh 在 Jackson Hole 发表主旨讲话。
- 2026-09-03 02:00（北京时间）：美联储公布 Beige Book。
- 下一次 FOMC 会议为 2026-09-15 至 09-16；声明和新闻发布会时间在进入未来 7 天窗口后展示。

免费数据架构：

- Finnhub 现有生产 Key：财报、IPO 等结构化公司事件主源
- Federal Reserve、BLS、BEA：三个官方宏观日历兜底
- 现有新闻流：仅从新 story 中提取明确的未来日期，补行业大会、产品发布会、政策会议等非标准事件
- NVIDIA Newsroom Press Release RSS：用于补充财报精确时间等官方公司公告

## 方案选择

### 采用：免费混合聚合

Finnhub承担公司日历聚合；三个美国官方日历只覆盖最重要宏观事件；新闻抽取补足非标准事件。已有 DeepSeek 调用只对新 story 输出未来时间，不增加重复调用。

### 未采用：第三方财经日历 API

覆盖广，但存在授权、API Key、限流和字段变更风险。

### 未采用：搜索新闻推断未来日程

覆盖不稳定，可能混入预测日期，也会持续消耗模型 Token。

## 数据契约

热点事件增加：

- `eventType: "news" | "upcoming"`
- `scheduledFor: string | null`，ISO 8601
- `tags.topic` 对未来事件强制包含 `未来事件`

未来事件规则：

- 仅保留未来 7 天；已经发生的事件退出未来列表，但对应结果新闻仍可作为普通新闻出现。
- “未来事件”筛选中按 `scheduledFor` 升序，最近事件优先。
- “全部”筛选中，未来事件先显示，普通新闻继续按 `publishedAt` 倒序。
- 官方日历事件直接生成中文摘要和影响资产标签，标记为 `official`、`complete`，不调用 DeepSeek。
- 上游日历失败时复用持久缓存；没有权威时间的数据不进入未来事件。

首批高影响事件：FOMC、Fed 主席/理事关键讲话、Beige Book、BLS 就业/CPI/PPI、BEA GDP/PCE、NVIDIA 财报及电话会。常规 H.15、CP 等低影响统计不进入默认未来事件。

## 页面

- 新增「未来事件」标签。
- 卡片显示北京时间、原时区时间和“今天 / X 天后”。
- 未来事件使用独立琥珀色标识，仍保留原始官方链接。

## PDF 固定结构

### 完整复盘：固定 3 页

1. 热点新闻榜：一页。顶部先放未来大事件，随后按宏观、地缘、能源、科技等模块排版；最多 12 条精选事件，模块内最新优先。
2. 个股资金榜：一页。标题和表头置顶；股票代码去重；通过紧凑表格容纳全部上榜个股，不产生续页。
3. 游资席位榜：一页。标题和表头置顶；最多展示 28 个席位，每个席位仅保留买入、卖出、净额及一只主要买入股票，不显示多行个股明细。

单独导出的热点、个股资金、游资 PDF 各自固定一页。取消封面页；每页保留主题色、水印、页码和免责声明。

## 失败与边界

- 官方来源失败：显示最近缓存并标记缓存来源；不编造日期。
- 内容超量：按重要度、官方/多源验证、时间优先级裁剪，不缩小到不可阅读字号。
- PDF 仍通过服务端生成并直接下载，保留 CDN 不可变缓存。
