# OSINT 游资买入流与刷新性能设计

## 目标

资金龙虎榜保留“个股资金榜”和“席位资金榜”两个入口；个股榜移除单只股票详情，席位榜改为“游资大佬今天买了什么”。同时扩充股票相关财经新闻并降低 OSINT 首屏与刷新等待时间。

## 展示口径

- 个股资金榜：保留净买入榜和净卖出榜，移除右侧单只股票详情、买五和卖五详情。
- 席位资金榜：主体为游资观察标签，而不是股票。
- 纳入：`category === "known-seat"` 且 `buyAmount > 0` 的公开龙虎榜席位。
- 排序：游资总买入额降序。
- 同一游资：合并其多个精确匹配席位；保留席位全名和 A/B/C 观察可信度。
- 同一股票：按游资标签与股票代码合并重复上榜原因，金额汇总，原因去重。
- 卡片信息：游资标签、总买入额、总卖出额、总净额、命中席位数、买入股票数。
- 股票明细：股票名称/代码、买入额、卖出额、净额、上榜原因；按买入额降序。
- 普通营业部、机构专用和股通席位不进入席位资金榜；它们仍可保留在兼容 API 中供其他 Agent 使用。
- “游资观察标签”只表示公开营业部与市场常用别名的观察映射，不证明真实账户身份。

## 数据契约

在龙虎榜快照中新增 `hotMoneyFlows`：

- `label`
- `confidence`
- `departmentNames[]`
- `totalBuyAmount`
- `totalSellAmount`
- `totalNetAmount`
- `stocks[]`

保留现有 `stocks` 与 `seatFlows`，避免破坏其他 Agent 的既有接入；页面请求轻量视图 `GET /api/osint/v1/lhb?view=dashboard`，返回个股排行与游资聚合结果，不返回每只股票的买五/卖五原始明细。

## 刷新性能

1. 龙虎榜轻量响应不再传输全量个股买五/卖五，目标将当前约 440KB 响应缩小 80% 以上。
2. 龙虎榜最近交易日快照增加短 TTL 与同进程请求合并，避免每次先串行查询最新交易日再拉三张表。
3. 页面行情与新闻改为独立请求、独立状态：行情完成即可先渲染，不等待新闻抓取与 DeepSeek。
4. 行情自动刷新使用较短轮询；新闻保持低频刷新；手动刷新并行触发两者。
5. 服务端保留最后成功快照；外部数据源失败时显示缓存态或 unavailable，不填充假数据。

## 新闻范围与分页

- 时间窗：最近72小时。
- 容量：服务端规范化缓存最多200条，数据充足时不少于50条。
- 分页：`GET /api/osint/v1/stories?page=1&pageSize=20&topic=宏观`；响应包含 `page`、`pageSize`、`total`、`totalPages`。
- 分类：地缘、宏观、能源、科技由服务端在完整72小时集合上过滤，再分页；不得只对当前20条做前端过滤。
- 相关性：仅保留股票市场、上市公司、宏观政策、利率汇率、能源大宗、地缘风险、产业政策和核心科技供应链新闻。
- 来源：保留新浪财经、东方财富、财联社、BBC/GDELT/ReliefWeb，并增加 Bloomberg 与 Reuters 的公开新闻索引、CNBC 官方 RSS、WSJ Markets RSS和监管/央行公开资讯。
- Bloomberg 仅使用公开标题、链接和可公开摘要；不绕过付费墙。
- Wind 正式资讯 API 需要授权。未配置授权前只尝试其公开网页索引并如实报告来源健康度，不宣称接入付费 Wind 数据。
- DeepSeek 只处理当前返回页的翻译、一句话摘要和标签；确定性标签先完成服务端分类，避免 AI 失败导致分类空白。

## 交互与空态

- 默认保留“个股资金榜 / 席位资金榜”切换；个股榜只显示净买入和净卖出排行。
- 没有已识别游资买入时显示“本交易日暂未识别到游资观察席买入”，不回退展示普通营业部。
- 刷新期间保留最近成功内容，仅刷新图标转动。
- 接口失败时明确显示来源异常和最近成功时间。

## 验证

- 契约测试先证明：只纳入 `known-seat + buyAmount > 0`、按买入额排序、多席位和同股原因正确合并。
- 轻量接口测试证明保留个股排行但不返回买五/卖五原始明细，并保持来源状态字段。
- 前端测试/静态检查证明个股榜切换仍存在且单股详情已移除。
- 新闻契约测试证明72小时窗口、至少50条容量、服务端分类后分页和分页元数据。
- 线上验收记录行情、新闻、龙虎榜接口耗时和龙虎榜响应体大小；核对至少一个游资标签及其买入股票。
